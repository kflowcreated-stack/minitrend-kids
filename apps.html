ဆိုင်ရှင်များ အော်ဒါစစ်ရန်နှင့် Stock ပို့ရန်

📲 ဆိုင် App ဖွင့်မည်

🚚 Delivery App (ပို့ဆောင်ရေးဝန်ထမ်း)

ပစ္စည်းကောက်ယူရန်နှင့် ပို့ဆောင်ရန်

📲 Delivery App ဖွင့်မည်

🔐 Admin Panel (ဆိုင်ပိုင်ရှင်သီးသန့်)

Password ရှိမှ ဝင်ရောက်နိုင်ပါသည်

🔓 Admin Panel ဖွင့်မည်

📲 ဖုန်း Screen ပေါ် App တင်နည်းနှင့် Noti ဖွင့်နည်း

🤖 Android (Chrome ဖြင့်ဖွင့်ပါ):

၁။ အပေါ်ညာဘက် အစက် ၃ စက် (⋮) → Install app / Add to Home screen ကို နှိပ်ပါ။

၂။ App ဖွင့်ပြီး 🔔 Noti ခလုတ်နှိပ်ကာ Allow ကို နှိပ်ပါ။

🍎 iPhone (Safari ဖြင့်ဖွင့်ပါ):

၁။ အောက်ခြေ Share (⬆️) → Add to Home Screen (➕) → Add နှိပ်ပါ။

၂။ Home Screen ပေါ်က App icon ကို ဖွင့်ပြီး 🔔 Noti ခလုတ်နှိပ်ကာ Allow ကို နှိပ်ပါ။
